# README



If you are reading this then you have downloaded a very basic json test generator written in the python programming language.



The purpose of this program is to make creating tests for gradescope easier and less complicated.



##### A couple notes about the project:



* In this project there are 3 files: this README.txt, an executable, and a .py file with the actual code

* The executable works only on windows

* The .py file is mainly meant for Linux and Mac users that want to generate their own executable for their OS,
or people thinking i am inviting them to download a virus. it can be run by anyone with a version of python 3.0 and above

* This project is currently a skeleton which provides the bare minimum of functionality to be useful.
It doesn't check for edge cases or valid inputs because currently I cant be fucked, and it had been tested 4 times with random inputs.



##### **How to use:**



* Enter the number of tests that you want to create

* The default for auto naming is no so if you don't want to manually name each test, be sure to enter y exactly

* If you are using copy paste to paste inputs and outputs,
notice that if you copy '\\n' from an ide or similar code editor,
it will read it as a newline character (enter key) and end the input earlier then was probably intended

* **NOTE:** At the end of the program a file called "student\_tests.json" will be generated at the location where the program was created.
This file is ready for use in gradescope, but I still recommend looking at it and checking that you wrote the inputs and outputs
correctly.
